# Раздел «Карта» (ven4PcConfig 1.3.0): план работ

> Выполняется в этой же сессии, задача за задачей. Код пишется сразу в файлы, а не в план. Здесь зафиксированы границы задач, интерфейсы и проверки. Спецификация: `docs/superpowers/specs/2026-11-25-karta-design.md`.

**Цель:** раздел «Карта» — этажи, кабинеты, ПК и принтеры, выгрузка в Visio, PNG, draw.io и лист Excel.

**Устройство:** модель карты и раскладка — чистый код без интерфейса и с проверками. Отрисовщик общий для холста, PNG и Excel. Генераторы файлов пишут через существующий `ZipWriter`. Интерфейс собран из уже готовых элементов темы.

**Технологии:** C# (LangVersion latest), net20, WinForms и System.Drawing. Проверки — xunit на net48.

## Общие ограничения

- Целевая платформа net20, без сторонних библиотек, работа от Windows XP до 11. В net20 нет LINQ и `HashSet`.
- Файлы карты лежат в `ven4PcConfig_данные\`: `карта.xml`, `настройки.xml`, `карта\` (подложки).
- Запись файлов идёт через временный файл с заменой. Повреждённые файлы не удаляются, а переименовываются.
- Тексты интерфейса — русские, в духе остальных разделов.
- Перед каждым коммитом — проверка commit-checker, атрибуции нет. Push и выпуск — только по слову владельца.

## Интерфейсы (общие для задач)

```csharp
// src/Map/MapDoc.cs
class Floor { public string Id, Name, Bg = ""; public int W = 1600, H = 1000; }
class Room  { public string Id, FloorId, Name, Dept = ""; public int X, Y, W, H; public bool Auto; public Rectangle Rect; }
class Place { public string Item, RoomId; public int X, Y; }
class MapDoc {
  public List<Floor> Floors; public List<Room> Rooms; public Dictionary<string, Place> Places;
  public static MapDoc Load(string path, out string error);   // нет файла → пустая карта, error = null
  public void Save(string path);
  public string NewId(string prefix);                          // "f3", "r12"
  public Floor FloorById(string id); public Room RoomById(string id);
}
// src/Settings.cs
class AppSettings { public bool Png, Drawio, XlsxSheet; public static AppSettings Load(string path); public void Save(string path); }
// src/Map/Printers.cs
class MapPrinter { public string Key, Name, Driver, Port; public bool Network; public List<PcRecord> Pcs; }
static class Printers { public static bool IsVirtual(string name); public static List<MapPrinter> FromPcs(List<PcRecord> pcs); }
// src/Map/MapLayout.cs
class MapItem { public string Key; public PcRecord Pc; public MapPrinter Printer; public Room Room; public Rectangle Rect; public string Line1, Line2, Grade; public bool IsPc => Pc != null; }
class ResolvedMap {
  public MapDoc Doc; public List<MapItem> Items;
  public List<Room> RoomsOn(Floor f); public List<MapItem> ItemsOn(Floor f);
  public Room RoomOfPc(PcRecord pc); public string RoomTitle(Room r);   // «2 этаж · 204», если этажей > 1
}
static class MapLayout {
  public const int CellW = 112, CellH = 64, Head = 34, Gap = 8;
  public static ResolvedMap Resolve(MapDoc doc, List<PcRecord> pcs); // добавляет auto-кабинеты в doc
  public static void Reset(MapDoc doc);                               // удаляет Places и auto-кабинеты
}
// src/Map/MapRenderer.cs
class MapPalette { public static MapPalette Dark, Light; ... }
static class MapRenderer {
  public static void DrawFloor(Graphics g, ResolvedMap m, Floor f, MapPalette p, Image bg, string currentPcKey, string selectedKey);
  public static Bitmap Render(ResolvedMap m, Floor f, string mapDir, MapPalette p);
}
// src/Map/VsdxWriter.cs, DrawioWriter.cs
static class VsdxWriter   { public static byte[] Build(ResolvedMap m, string mapDir); }
static class DrawioWriter { public static string Build(ResolvedMap m, string mapDir); }
// src/Xlsx.cs
class XImage { public byte[] Png; public int Row, Col, W, H; }   // XSheet.Images
// src/Session.cs
public MapDoc Map; public AppSettings Settings; public string MapPath, SettingsPath, MapDir;
public void LoadMap(); public void SaveMap(); public ResolvedMap ResolveMap();
// src/Map/MapExport.cs
static class MapExport { public static List<string> Export(Session s, List<string> errors); } // пути записанных файлов
```

## Задачи

### 1. Проект проверок
- `tests/PcInventory.Tests/PcInventory.Tests.csproj`: net48, xunit, ссылка на `../../src/PcInventory.csproj`. Проверка-заглушка `Util.Join`.
- `src/AssemblyInfo.cs`: `InternalsVisibleTo("PcInventory.Tests")`.
- В `build.yml` перед сборкой добавляется шаг `dotnet test tests/PcInventory.Tests -c Release`.
- Проверка: `dotnet test` проходит.

### 2. Модель карты и настройки
- `src/Map/MapDoc.cs`, `src/Settings.cs`.
- Проверки:
  - круговая запись и чтение (этажи, кабинеты, места, кириллица, `\\srv\q` в ключе);
  - отсутствующий файл даёт пустую карту без ошибки;
  - битый XML даёт `error` и переименованный файл;
  - `NewId` не повторяется.

### 3. Принтеры и раскладка
- `src/Map/Printers.cs`, `src/Map/MapLayout.cs`.
- Проверки:
  - три ПК в двух отделах дают 2 auto-кабинета на «1 этаже»;
  - ПК без отдела попадает в «Без отдела»;
  - `RoomId` указывает на существующий кабинет — ПК стоит там; на удалённый кабинет — ПК уходит в кабинет отдела;
  - кабинет админа, привязанный к отделу, используется вместо auto;
  - сохранённый `Place` соблюдается;
  - сетевой принтер у двух ПК даёт один значок, у которого 2 ПК;
  - виртуальный принтер отсеивается;
  - auto-кабинет вмещает все значки;
  - `Reset` оставляет кабинеты админа.

### 4. Отрисовщик и PNG
- `src/Map/MapRenderer.cs`: подложка, кабинеты, значки. В светлой палитре значки рисуются фигурами (без шрифта значков), чтобы PNG был одинаковым на любой Windows.
- Проверка: `Render` возвращает картинку размером с этаж, пиксель кабинета не равен фону.

### 5. Visio
- `src/Map/VsdxWriter.cs`.
- Проверки:
  - архив разбирается, все части из спецификации на месте, каждый XML загружается в `XmlDocument`;
  - страниц столько, сколько этажей;
  - фигур на странице — кабинеты плюс значки (плюс подложка);
  - у фигуры ПК есть `Section N="Property"` со строкой «Процессор»;
  - `[Content_Types]` содержит png, если есть подложка.
- Ручная проверка: LibreOffice `soffice --headless --convert-to pdf Карта_АРМ.vsdx` на тестовом ПК.

### 6. draw.io
- `src/Map/DrawioWriter.cs`.
- Проверки: XML разбирается, `diagram` по числу этажей, у `object` ПК есть атрибут «Процессор», `parent` значка равен id кабинета.

### 7. Excel: картинки, лист «Карта», колонка «Кабинет»
- `src/Xlsx.cs` (`XImage`, drawing, media, связи), `src/Program.cs` (`Report`).
- Проверки:
  - книга с картинкой содержит `xl/drawings/drawing1.xml`, `xl/media/image1.png`, связь листа и `<drawing r:id>`; все XML разбираются;
  - колонка «Кабинет» идёт сразу после «Отдел».

### 8. Сессия и выгрузка
- `src/Session.cs`: `LoadMap`, `SaveMap`, `ResolveMap`, загрузка `Settings`. `Load()` читает карту.
- `src/Map/MapExport.cs`: имена файлов, занятые файлы (копия с меткой времени).
- `Report.Build` получает лист «Карта», если `Settings.XlsxSheet`.
- Проверка: `MapExport` во временной папке пишет `.vsdx`, а при включённых галочках ещё PNG и `.drawio`.

### 9. Окно: «Карта»
- `src/Gui/MapCanvas.cs`: масштаб, сдвиг, перетаскивание кабинетов и значков, ручка размера, подсказки, двойной щелчок, `Delete`.
- `src/Gui/MapPage.cs`: заголовок, кнопки, вкладки этажей с меню.
- `src/Gui/Dialogs.cs`: «Кабинет», «Название», «Сведения о ПК», «Подтверждение».
- `src/Gui/MainForm.cs`: навигация из 5 пунктов, разделитель перед «Настройками», подключение страницы.
- Проверка: снимки `/shot` с демо-данными.

### 10. Окно: «Кабинет» в карточке и «Настройки»
- `src/Gui/MainForm.cs`: поле «Кабинет» в карточке АРМ, сохранение `RoomId`.
- `src/Gui/SettingsPage.cs` и переключатель `Toggle` в `Controls.cs`.
- Проверка: снимки `/shot`.

### 11. Демо-данные и вид
- `src/Gui/Demo.cs`: два этажа, подложка — нарисованный кодом план, кабинеты отделов и кабинет админа, сетевой и локальный принтеры.
- `TakeShots` снимает «Карту» и «Настройки».
- Просмотр снимков. Согласование с Argon — по слову владельца, это траты kie.

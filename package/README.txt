ven4PcConfig — сбор сведений об АРМ в реестр Excel
====================================================

Как пользоваться
  1. Скопируйте папку целиком на флешку. Файл ven4PcConfig.exe.config
     должен лежать рядом с exe: он позволяет запускаться и на старом,
     и на новом .NET.
  2. На каждом ПК запустите ven4PcConfig.exe. Права администратора
     не обязательны, но с ними собирается больше: износ и температура
     дисков, прогноз отказа SMART и программы других пользователей ПК.
     Откроется окно в стиле Ven4Tools. Сбор сведений идёт сам, 3–10 секунд,
     затем в разделе «Этот компьютер» видно, что найдено, а справа —
     карточка АРМ:
       - отдел: выберите из списка (стрелка справа) или впишите новый;
       - кабинет: пусто — ПК встанет на карте в кабинет своего отдела;
         можно выбрать кабинет из списка или вписать новый;
       - номер АРМ: подсказывается следующий по отделу, например 1.3;
       - ФИО сотрудника: подставляется из учётной записи, если найдено;
       - примечание — необязательно.
     Нажмите «Сохранить в реестр» (или Enter в любом поле).
     Если программа запущена без прав администратора, в «Сообщениях»
     есть кнопка «Перезапустить от имени администратора».
  3. Рядом с exe обновится Реестр_АРМ.xlsx — общий файл по всем ПК.
     Раздел «Реестр» в окне показывает все ПК, что требует внимания,
     и кнопки «Открыть Excel», «Пересобрать», «Папка данных».
  4. Раздел «Карта» — ПК и принтеры по кабинетам и этажам:
       - кабинеты отделов программа рисует сама; «Кабинет +» добавляет свой;
       - «Подложка…» кладёт под этаж план помещений (PNG или JPG);
       - значки и кабинеты перетаскиваются мышью, кабинет растягивается
         за правый нижний угол, колесо мыши — масштаб;
       - двойной щелчок по ПК — все сведения, по кабинету — его настройки;
       - правый щелчок по вкладке этажа — переименовать, убрать подложку,
         удалить; «+» — новый этаж;
       - «Выгрузить» записывает рядом с exe Карта_АРМ.vsdx (Visio 2013+);
         в разделе «Настройки» можно добавить PNG, draw.io и лист «Карта»
         в Excel.

Что лежит рядом с exe
  Реестр_АРМ.xlsx         реестр, 5 листов:
                           «Сводка» — что требует внимания (активация,
                             антивирус, ОС без поддержки, диски, место,
                             ОЗУ), операционные системы, отделы;
                           «Реестр» — как в сводном реестре АРМ, по отделам;
                           «Лицензии» — активирована ли Windows и Office,
                             антивирус: состояние и срок;
                           «Комплектующие» — модули ОЗУ, диски, мониторы,
                             сеть, принтеры с серийными номерами;
                           «Программы» — установленное ПО и для кого
                             оно установлено (все пользователи или кто-то
                             один).
  Карта_АРМ.vsdx          карта для Visio — после кнопки «Выгрузить».
  ven4PcConfig_данные\    по одному XML на каждый ПК. Из них собирается Excel.
                          Там же карта.xml, настройки.xml и папка «карта»
                          с подложками этажей.

Важно
  - Excel каждый раз пересобирается из XML. Правки, сделанные прямо
    в xlsx, при следующем запуске пропадут. Отдел, номер, ФИО
    и примечание меняйте повторным запуском на нужном ПК.
  - Повторный запуск на том же ПК обновляет его строку, а не добавляет новую.
  - Если Реестр_АРМ.xlsx открыт в Excel, реестр сохранится в файл
    с датой в имени.
  - Данные с нескольких флешек объединяются копированием XML
    в одну папку ven4PcConfig_данные и запуском с ключом /rebuild.
  - Флешки и внешние USB-диски в накопители не попадают.
  - Если ПК переименовали, программа узнаёт его (UUID платы вместе
    с MAC-адресом сетевой карты или серийным номером) и обновляет
    прежнюю строку.
  - Если часть сведений собрать не удалось, программа пишет, что именно,
    а на листе «Сводка» такой ПК попадает в «Требует внимания».

Лицензии и активация
  Колонки «Активация Windows», «Активация Office», «Антивирус: состояние
  и лицензия» и «Состояние дисков» подсвечены: зелёным — всё в порядке,
  красным — требует внимания (не активировано, истекло, выключено,
  неисправен).
  - Windows и Office: только факт — активировано или нет (для
    неактивированной копии — сколько дней осталось). Способ активации,
    ключ и сервер активации не собираются и в реестр не попадают;
    файлы данных версии 1.0 при первом же запуске переписываются
    без них.
    Понимает Office 2010–2024, LTSC и Microsoft 365.
    Для Office 2003/2007 активация программно не проверяется.
  - Антивирус: название, включён ли, свежие ли базы и не истекла ли
    лицензия — по данным Центра безопасности Windows. Точную дату
    окончания лицензии Windows не сообщает, её показывает только консоль
    самого антивируса. Исключение — Dr.Web: дата берётся из ключевого файла.

Состояние дисков
  Исправность по данным Windows. С правами администратора добавляются
  износ SSD, температура, наработка в часах и прогноз отказа SMART.
  Красным: неисправен, прогноз отказа, износ от 90 %, неисправимые
  ошибки чтения/записи, температура от 70 °C.

Программы других пользователей
  Без прав администратора читаются программы «для всех» и текущего
  пользователя. С правами администратора — ещё и всех остальных
  пользователей ПК: их разделы реестра подключаются только на время
  чтения и сразу отключаются.

Параметры запуска (без параметров открывается окно)
  /auto      без окна и без вопросов (отдел/номер/ФИО берутся из прошлого
             запуска) — для скриптов и групповых политик
  /rebuild   только пересобрать Excel из сохранённых данных
  /console   работа в консоли с вопросами, как в версии 1.0
  /nopause   не ждать нажатия клавиши в конце

Совместимость
  Windows XP SP2/SP3, Vista, 7, 8, 8.1, 10, 11 и серверные версии,
  32 и 64 бита. Использует встроенный в Windows .NET Framework
  (2.0/3.5 или 4.x). На XP нужен любой установленный .NET 2.0–4.0.
